## Key Concepts

### Missing Values
Handling missing numerical and categorical values using appropriate techniques such as mean, median, and mode.

### Feature Scaling
- **StandardScaler:** Standardizes features with mean ≈ 0 and standard deviation ≈ 1.
- **MinMaxScaler:** Scales features to a fixed range, usually 0 to 1.

### Encoding
- **LabelEncoder:** Converts categories into numerical labels, mainly for target variables.
- **One-Hot Encoding:** Converts categorical features into binary columns.

### Normalization
**Normalizer** scales each row to unit magnitude while preserving its direction.
